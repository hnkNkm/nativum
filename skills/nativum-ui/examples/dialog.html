Dialog

ネイティブの <dialog> / <dialog open> が Core。 対応環境では command / commandfor で宣言的に開閉する (Enhancement)。 カスタムmodal実装は禁止。

モーダルダイアログ (commandfor)

設定

Escキーでのキャンセルとフォーカストラップはブラウザが提供する。 form="..." が参照するのは <form> のidである (<dialog> のidではない)。

確認ダイアログ (サーバーへのPOST)

プロジェクトを削除しますか?

この操作は取り消せません。プロジェクトと全データが削除されます。

状態変更はサーバーへの通常の <form method="post"> 送信で行う。 <form method="dialog"> は returnValue を JavaScriptで読み取る用途のみで、サーバー送信はしない。

フォールバック: dialog[open] + ページ内フォーム

Invoker Commands 非対応環境では、サーバーが open を付けてレンダリングし、 操作はページ内の通常フォームで行う。この節は commandfor なしで操作できる。

プロフィールを編集
非モーダルのオーバーレイには <dialog> ではなく Popover API が 適切なprimitiveである。command="show" / command="hide" は dialogに定義されていないため使用しない。
