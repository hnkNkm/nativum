Dialog

ネイティブの <dialog> を使用する。カスタムmodal実装は禁止。 開閉はHTML Standardの command / commandfor 属性で宣言的に行う。

Modal dialog (commandfor)

Settings

Escキーでのキャンセルとフォーカストラップはブラウザが提供する。 実際のアプリでは action にサーバーエンドポイントを指定し、送信結果に応じてサーバーが再レンダリングする。

Confirm dialog (server form)

Delete project?

この操作は取り消せません。プロジェクトと全データが削除されます。

状態変更はサーバーへの通常の <form method="post"> 送信で行う (<form method="dialog"> は returnValue をJavaScriptで読み取る用途のみで、サーバー送信はしない)。

非モーダルのオーバーレイには <dialog> ではなく Popover API が適切なprimitiveである (Popover 参照)。 command="show" / command="hide" はdialogに定義されていないため使用しない。
commandfor に対応しない環境では、<dialog> はフォールバックとして open 属性付きでサーバーレンダリングし、操作対象をページ内のフォームへ置き換えることを推奨する。
